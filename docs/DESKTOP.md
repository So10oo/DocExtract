# Руководство по десктоп-приложению DocExtract

Операторское приложение — рабочий инструмент вокруг SDK: очередь файлов, просмотр страницы, правка текста, зоны и экспорт. Пайплайн распознавания тот же, что у библиотеки: PDF / Office / картинки → текст с координатами.

Окно называется **DocExtract — оператор**. Интерфейс переключается между русским и английским.

## Запуск

Из корня репозитория (нужен .NET 10 SDK):

```powershell
dotnet run --project src/DocExtract.Desktop
```

Готовая поставка (после `packaging/pack-desktop.ps1`):

- установщик `artifacts/releases/DocExtract-win-Setup.exe`
- портативный архив `artifacts/releases/DocExtract-win-Portable.zip`

Приложение рассчитано на **Windows 10/11**.

### Модели OCR

Для сканов и картинок нужны три ONNX-файла в каталоге `models/` (рядом с репозиторием или рядом с exe):

- `ch_PP-OCRv5_det_mobile.onnx`
- `eslav_PP-OCRv5_rec_mobile.onnx`
- `ch_PP-LCNet_x0_25_textline_ori_cls_mobile.onnx`

Скачивание:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/download-models.ps1
```

Если моделей нет, в статусной строке появится предупреждение. **Цифровые PDF с текстовым слоем и текст DOCX/XLSX** по-прежнему извлекаются.

## Окно

Три колонки и панель кнопок сверху.

1. **Очередь** слева — список файлов и статус.
2. **Просмотр** в центре — страница документа, оверлей слов, выделение прямоугольника.
3. Вкладки справа: **Текст**, **Зоны**, **Настройки**.

Справа вверху панели — строка статуса (готовность, ошибка, путь экспорта).

## Поддерживаемые файлы

| Формат | Что происходит |
|--------|----------------|
| PDF | Если включён текстовый слой и на странице достаточно символов — берётся он. Иначе страница рисуется и идёт в OCR. Смешанный PDF обрабатывается **постранично**. |
| DOCX, XLSX | Текст из разметки; встроенные картинки DOCX — отдельные страницы через OCR. |
| PNG, JPEG, TIFF, WebP, BMP | OCR по изображению. |

Многостраничные PDF листаются кнопками **◀** / **▶** (счётчик страниц **с нуля**: `Страница 0/3` — первая из трёх).

## Очередь

1. **Файлы…** — выбрать один или несколько документов.
2. **Папка…** — добавить все подходящие файлы из папки (без вложенных каталогов).
3. **Обработать** — прогнать все элементы со статусом `Pending` или `Error`.
4. **Повтор** — ещё раз обработать выбранный файл.
5. **Удалить** — убрать выбранный файл из очереди.

Статусы в списке: `Pending` (ожидает), `Running` (в работе), `Done` (готово), `Error` (ошибка и текст в красной строке).

Пока идёт обработка, кнопка **Обработать** недоступна.

После успешного прогона, если в настройках задана **папка экспорта**, туда сразу пишутся `.txt` и `.json` (имя как у исходного файла).

## Просмотр и оверлей

Выберите файл в очереди — в центре появится превью страницы.

- **Оверлей слов** — зелёные рамки по словам после распознавания.
- Синие рамки — зоны шаблона на текущей странице.

Превью доступно и до OCR (рендер страницы). Рамки слов появятся после **Обработать**.

## Сегмент страницы

Режим **Сегмент** (кнопка-переключатель на панели):

1. Включите **Сегмент**.
2. На странице зажмите мышь и растяните прямоугольник.
3. После отпускания выбранный фрагмент распознаётся отдельно.

Текст сегмента попадает на вкладку **Текст**. Координаты в результате считаются относительно **всей** страницы.

Выключите **Сегмент**, чтобы случайно не запускать распознавание при каждом выделении.

## Правка текста

Вкладка **Текст** — распознанный текст выбранного файла. Его можно править вручную.

**Экспорт** сохраняет:

- `.txt` — содержимое этой вкладки (уже с правками);
- `.json` — структурированный результат SDK (`schemaVersion: 1`). Если текст правили, в JSON добавляется поле `correctedText`.

Если папка экспорта в настройках пустая, **Экспорт** сначала спросит каталог.

## Зоны и шаблоны

Шаблоны нужны, чтобы заранее разметить поля на образце. **Извлечение значений полей по шаблону в этой версии ещё не делается** (этап 1 roadmap). Рисование, имена и файлы `.dex-template.json` уже работают.

1. В поле **Имя зоны** задайте имя (например `invoiceNumber`).
2. Включите **Рисовать зону**.
3. Выделите прямоугольник на странице — зона появится в списке (синяя рамка на превью).
4. Имя можно поправить в списке. Рядом указан индекс страницы.
5. **Сохранить шаблон** / **Загрузить шаблон** — файл `*.dex-template.json`.

Координаты зон **нормализованные (0…1)**, не зависят от DPI.

## Настройки

Вкладка **Настройки**. Чтобы они применились к следующему распознаванию, нажмите **Сохранить настройки**.

| Параметр | Смысл |
|----------|--------|
| Язык интерфейса | **Русский** / **English** |
| Языки OCR | флажки RU и EN (сейчас локальный движок всё равно использует смешанную модель ESLAV) |
| GPU | `Auto` — попробовать DirectML, иначе CPU; `Off` — только CPU |
| DPI растра | 72–400, шаг 25. Выше — чётче сканы, медленнее и больше памяти |
| Текстовый слой PDF сначала | не гонять OCR по цифровым страницам |
| Папка экспорта | автосохранение после обработки и цель для **Экспорт** |

Настройки пишутся в `%AppData%\DocExtract\settings.json`.

## Типичный сценарий

1. При необходимости скачайте модели.
2. Запустите приложение, при желании выставьте DPI и папку экспорта, **Сохранить настройки**.
3. **Файлы…** или **Папка…**.
4. **Обработать**.
5. Выберите файл, проверьте оверлей и текст, поправьте ошибки.
6. **Экспорт**, если папка не задана заранее.

Для вырезки печати/шапки: **Сегмент** → прямоугольник.

Для будущего разбора полей: **Рисовать зону** → сохранить `.dex-template.json`.

## Ограничения этой версии

- Нет таблиц, рукописи, галочек, QR и детекции печатей.
- Выход только TXT и JSON, не searchable PDF / DOCX.
- Значения полей из шаблона зон не извлекаются.
- Linux и macOS пока не поддерживаются.

Подробности следующих этапов: [ROADMAP.md](ROADMAP.md).

## Если что-то пошло не так

| Симптом | Что проверить |
|---------|----------------|
| Предупреждение про ONNX-модели | `tools/download-models.ps1`, файлы в `models/` рядом с exe |
| Скан «пустой», а цифровой PDF читается | модели на месте; для скана нужен OCR |
| Плохое качество скана | поднять DPI, убедиться что GPU `Auto` или `Off` работает, страница не слишком мелкая |
| Ошибка в очереди | красный текст под именем файла; **Повтор** после исправления (файл не занят, путь существует) |
| Нет превью | формат из списка выше; PDF не повреждён и не с паролем |
| Экспорт «тихий» | задайте папку в настройках или нажмите **Экспорт** и выберите каталог |
